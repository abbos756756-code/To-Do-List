# 📝 Zamonaviy To-Do List (Vazifalar Menejeri & Budilnik)

HTML5, zamonaviy CSS3 (Glassmorphism & Dark Mode) va toza JavaScript (ES6+) asosida yaratilgan interaktiv va chiroyli vazifalar menejeri.

## ✨ Imkoniyatlar

- 🎨 **Zamonaviy Glassmorphism dizayn**: Neon nurlar, mayin animatsiyalar va qulay to'q mavzu (Dark Mode).
- ⏰ **Budilnik va Ovozli Eslatma**: Belgilangan vaqt yetib kelganda Web Audio API orqali yoqimli va baland qo'ng'iroq (chime bell) tovushi yangraydi.
- 🔔 **Desktop Bildirishnomalar**: Brauzer boshqa oynada turganda ham kompyuter ekraniga eslatma xabari chiqadi.
- 📊 **Progress Bar va Statistika**: Vazifalar bajarilish darajasi foizda real vaqt rejimida hisoblanadi.
- 🏷️ **Muhimlik darajalari**: 🟢 Oddiy, 🟡 O'rta, 🔴 Yuqori (Priority badges).
- 🔍 **Tezkor qidiruv va filtrlash**: Barchasi, Jarayonda, Bajarilgan vazifalar bo'yicha saralash.
- 💾 **Doimiy xotira (LocalStorage)**: Sahifa yangilansa yoki yopilsa ham barcha rejalaringiz xotirada saqlanadi.
- 📱 **Mobil moslashuvchanlik**: Telefon va planshet ekranlariga to'liq moslashgan.

## 🚀 Texnologiyalar

- **HTML5**: Semantik tuzilma va qulay formalar.
- **CSS3**: CSS Variables, Glassmorphism (`backdrop-filter`), animatsiyalar va Flexbox.
- **JavaScript (Vanilla)**: LocalStorage, Web Audio API, Notification API, Event Delegation.
